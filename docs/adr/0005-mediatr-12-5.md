# MediatR fixado na versão 12.5.0

A partir da versão 13, o MediatR passou a usar licença recíproca (RPL-1.5) ou licença comercial com chave. O projeto fixa a 12.5.0, última versão Apache-2.0, que cobre tudo o que é usado aqui (`ISender`, `IRequestHandler` e `IPipelineBehavior`). Qualquer atualização exige rever a licença antes.
